Each session's stack is its own row, so you read the agents side by side. Shared services sit on top, leftovers at the bottom. It gets tall with many agents or a big stack.

The infrastructure is drawn once, as the files describe it. Each service carries a chip for every copy, so you see the shape of the system first and who runs what second. It stays compact as agents multiply, but one agent's whole stack is spread across the map.
